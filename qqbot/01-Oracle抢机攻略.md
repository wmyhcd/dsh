# Oracle Cloud 永久免费机器 · 抢机攻略

## 免费额度（Always Free，永久，不是试用）

| 资源 | 额度 |
|---|---|
| ARM 虚拟机（Ampere A1） | **共 4 OCPU + 24 GB 内存**，可切分成多台 |
| x86 虚拟机 | 2 台 1/8 OCPU + 1 GB 内存（太小，跑不动机器人） |
| 块存储 | 总共 200 GB |
| 出站流量 | 每月 10 TB |
| 公网 IP | 每台实例 1 个 |

**关键：你要的是 ARM 那 4 核 24G，不是那两台 x86 小鸡。** 后者 1GB 内存跑不动。

建议切分方案（跑一个 QQ 机器人足够了）：

```
1 台 2 OCPU / 12 GB  ← 全副身家放这台
```

剩下的可以先不建，留着以后用。

## 注册前先确认三件事

1. **一张能用的卡**（Visa / Mastercard 借记卡或信用卡都行）
   - 会扣 1 美元验证，马上退回
   - 卡要能境外支付，国内大多数双币卡可以
2. **一个邮箱**（Gmail / QQ 邮箱都行，别用一次性邮箱）
3. **能收短信的手机号**

## 注册流程

### ① 打开注册页
https://signup.oraclecloud.com

### ② 国家选「中国」还是别的？

这一步有个坑：**填的中国地址和卡的账单地址要一致**。不一致容易被拒。

### ③ 【最关键】Home Region 选择

**这一项选了就不能改，而且直接决定你能不能抢到 ARM 机器。**

| 区域 | ARM 库存 | 到中国大陆延迟 | 推荐度 |
|---|---|---|---|
| **日本大阪** | 极难 | 40–70 ms | ⭐⭐⭐ 抢到就是最优 |
| **韩国首尔** | 极难 | 50–80 ms | ⭐⭐⭐ 同上 |
| **新加坡** | 极难 | 60–100 ms | ⭐⭐ |
| **美国圣何塞** | 较好抢 | 150–200 ms | ⭐⭐ 抢不到就选它 |
| **美国凤凰城** | 较好抢 | 180–230 ms | ⭐ 备胎 |

**对你的用途（QQ 机器人），延迟其实无所谓** —— 机器人是挂在服务器上自己跑，跟腾讯服务器通信，你人在国内感受不到那个延迟。

所以策略是：**想要体验好 → 冲大阪/首尔；想稳妥拿到 → 直接选圣何塞。**

> 抢不到库存比延迟高 100ms 痛苦一万倍。这是过来人的顺序。

### ④ 填地址、验证卡、验证手机

卡验证失败常见原因：
- 卡没开境外支付 → 打银行客服开
- 卡里余额不足 1 美元
- 姓名拼音和卡面不一致

### ⑤ 等邮件

通常几分钟到几小时。到了就能登控制台。

## 抢 ARM 库存

进控制台后：

```
菜单 → Compute → Instances → Create Instance
```

**镜像选 Canonical Ubuntu 22.04 或 24.04**（ARM 版）

**Shape 选 `VM.Standard.A1.Flex`**，OCPU 填 2，内存填 12 GB

点创建。**大概率会看到：**

```
Out of host capacity
```

这就是没库存。**不要放弃，这是常态。**

### 四个增加成功率的办法

**1. 换 Availability Domain**
创建页面上有个 AD 下拉框（AD-1 / AD-2 / AD-3），挨个试。

**2. 换时间点抢**
亚洲时间凌晨 3–6 点成功率明显高（那是美洲的白天，别人在睡觉）。

**3. 升级成 Pay As You Go 账户**（重要）

免费账户（Free Tier）抢 ARM 的优先级**低于**付费账户。升级成 PAYG 后：
- 仍然享受同样的永久免费额度
- 但抢库存优先级大幅提升
- **只要不超出免费额度，一分钱不扣**

升级入口：控制台右上角 → 账户 → Upgrade to Pay As You Go

> ⚠️ 代价：一旦超出免费额度（比如多建了机器、多用了存储），会真的扣钱。所以升级后自己要盯着点，别乱建。

**4. 用脚本自动轮询**

手动点太累。写个脚本每 30 秒试一次创建，抢到就停。

需要先配 API Key（控制台 → 用户设置 → API Keys → 添加），然后跑 Python 脚本用 OCI SDK。

**这个脚本我可以帮你写好，你只要把 API 配置发我。**

## 拿到机器之后

1. 记下**公网 IP**
2. 下载 **SSH 私钥**（创建时让你存的，丢了就连不上）
3. 用手机 SSH 客户端（Termius / JuiceSSH）或者直接让 DSH 的容器连

然后交给我，我做这些：

- 装 Node.js 22
- 部署 NapCat（QQ 登录）
- 部署消息处理服务
- 接 AI API
- 配开机自启 + 掉线重连

## 如果实在抢不到

备选顺序：

1. **观察两周**。Oracle 每隔一段时间会放库存，很多人蹲到过。
2. **换成 x86 那两台小鸡**（1GB 内存），装个精简版机器人勉强能跑一个号，但很挤。
3. **转便宜 VPS**，$2–4/月，5 分钟开好，不折腾。

## 一句话总结

> 注册时选 **圣何塞** 最稳，登进去直接建 ARM，报 Out of host capacity 就换 AD 重试，
> 想要更高成功率就 **升级 PAYG**，实在不行 **凌晨 3 点试**。
